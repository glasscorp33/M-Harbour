Click inside the page, then use the keyboard as on the Cardputer: ↑/↓ (or ; / .) to move, Enter to choose, Esc (or `) to go back, letters for the shortcuts shown at the bottom of each screen. The flow

  1. Home: Recovery or Firmware manager.
  2. Connect: one instruction screen, ENTER.
  3. Waiting: switch the device on; the Cardputer finds it and asks it over MIDI to open download mode by itself (no "not download mode" screen).
  4. Main menu: Backup current · Library · Load firmware. The top line says what is on the device and whether it is saved.
  5. Backup current: pick a folder (or make one; the newest name in it is shown). The name window lists the names already in that folder, so you can follow the same format: ↑↓ look through them, Tab copies one into the field to edit.
  6. Library: folders, then backups inside. N rename, M move to, D delete, F new folder.
  7. Load firmware: if what's on the device is not saved, it asks first (Yes → folder + name, No → straight on). Then pick the firmware, confirm, write.
  8. I (main menu): info page with battery, SD space and the log. X: exit and restart the device.
